# Vincent's ML Portfolio Website

Modern, responsive portfolio website built with Next.js 14 to showcase machine learning and AI projects.

## ✅ BUILD STATUS: READY FOR DEPLOYMENT

All ESLint errors fixed! See `ESLINT_FIXES.md` for details.

## 🚀 Quick Start

**Just double-click:**
```
DOUBLE_CLICK_ME.bat
```

This will install dependencies and start your website at http://localhost:3000

## 📝 Managing Projects

See `HOW_TO_MANAGE_PROJECTS.md` for detailed instructions.

**Quick version:**
1. Copy `content/projects/example-new-project.md`
2. Rename and edit it
3. Save - project appears automatically!

**To delete a project:** Delete the .md file

## 🎨 Customization

- **Your Info**: Edit `app/about/page.tsx` and `app/contact/page.tsx`
- **Colors**: Edit `styles/variables.css`
- **Images**: Add to `public/images/projects/`

## 🏗️ Project Structure

```
├── app/              # Pages (homepage, projects, about, contact)
├── components/       # React components
├── content/projects/ # Your project markdown files
├── styles/           # CSS styling
└── public/images/    # Images
```

## 📦 Available Batch Files

- **DOUBLE_CLICK_ME.bat** - Complete setup + start (use this first time)
- **INSTALL.bat** - Just install dependencies
- **START_SERVER.bat** - Just start the server (use after first install)
- **CHECK_BUILD.bat** - ⭐ Verify build passes (run before deploying)
- **PUSH_TO_GITHUB.bat** - Commit and push changes to GitHub
- **BUILD.bat** - Build for production

## 🛑 Stopping the Server

Press `Ctrl + C` in the terminal window

## 🚀 Deployment

**To deploy to Vercel:**

1. Double-click **`CHECK_BUILD.bat`** to verify build passes
2. Double-click **`PUSH_TO_GITHUB.bat`** to push to GitHub
3. Go to vercel.com and import your repository
4. Done!

See `DEPLOYMENT_GUIDE.md` for detailed instructions.
