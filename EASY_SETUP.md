# Easy Setup - Just Double Click! 🖱️

Hey Vincent! I created batch files you can double-click since command line isn't working.

## 🎯 Quick Start (Easiest!)

**Just double-click this file:**
```
DOUBLE_CLICK_ME.bat
```

This will automatically:
1. ✅ Clean old files
2. ✅ Install dependencies
3. ✅ Start the server
4. ✅ Open your browser to http://localhost:3000

**That's it!** Your website will be running!

---

## 📦 Or Do It Step by Step

### Step 1: Install
Double-click:
```
INSTALL.bat
```
Installs all dependencies (takes 1-2 minutes)

### Step 2: Start Server
Double-click:
```
START_SERVER.bat
```
Starts the dev server at http://localhost:3000

---

## ❓ Why Can't I Run Commands Directly?

Your Windows has PowerShell script execution disabled for security. That's why I created these batch files - they work without those restrictions!

The batch files do exactly what the commands would do, just automatically.

---

## 🎉 What to Expect

After running **DOUBLE_CLICK_ME.bat**, you'll see:

1. ✅ Terminal window opens
2. ✅ Shows installation progress
3. ✅ Browser opens to http://localhost:3000
4. ✅ Your portfolio website loads!

Then you can:
- Click on projects (they'll work now!)
- Browse your portfolio
- Make changes to files

---

## 🛑 To Stop the Server

In the terminal window that opened:
- Press `Ctrl + C`
- Then press `Y` to confirm
- Close the window

---

## 🔄 To Start Again Later

Just double-click:
```
START_SERVER.bat
```

No need to reinstall! Only run INSTALL.bat if you change dependencies.
